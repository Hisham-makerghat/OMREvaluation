# Working rules for this repository

## Git commits
- Every commit is authored and committed as the repository owner only:
  `Hisham <hisham@makerghat.org>` (GitHub: Hisham-makerghat).
- Never set Claude, Anthropic or any AI name as author or committer, and never add
  `Co-Authored-By`, `Claude-Session` or similar attribution trailers to commit messages.
- Pull request descriptions likewise carry no AI attribution footer.
